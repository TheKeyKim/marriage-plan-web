# 결혼 준비 체크리스트 (웹)

한국 예비부부의 결혼 준비 항목을 관리하는 순수 HTML/CSS/JS 웹앱입니다. 빌드 도구·서버 없이 브라우저만으로 동작합니다.

> 이 저장소는 **개인정보가 없는 공개 템플릿**입니다. 실제 이름·업체·금액 등은 코드에 넣지 말고, 앱에서 편집한 내용을 브라우저(localStorage)나 별도 비공개 저장소에 보관하세요.

## 기능

- **개요 / 상세 표** 두 화면 · 분류 필터
- 필수 / 선택 구분, 완료 체크(= 완납)
- 금액 계산: 예상 총액 · 💰 낸 돈 · 🧾 앞으로 낼 돈
- 되돌리기(undo), JSON 파일 저장/열기
- 변경사항 브라우저 자동 저장(localStorage)

## 실행

정적 파일이라 그대로 열면 됩니다.

```bash
python3 -m http.server 8080
# http://localhost:8080
```

또는 GitHub Pages로 배포해 링크로 접속할 수 있습니다 (Settings → Pages → Branch: main).

## 파일 구조

```
├─ index.html      # 대시보드 + 개요/표
├─ css/styles.css  # 스타일
└─ js/
   ├─ data.js      # 초기 데이터(빈 템플릿) — 개인정보 넣지 말 것
   └─ app.js       # 렌더링 · 편집 · 계산 · 파일 저장
```

## 개인정보 원칙

- 실제 데이터는 이 공개 저장소에 커밋하지 않습니다.
- `js/data.js`는 항상 플레이스홀더(신랑/신부, 예시 값 없음)만 유지합니다.
